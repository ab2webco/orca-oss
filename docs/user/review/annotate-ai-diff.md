# Annotate AI diffs

You can leave notes on a diff, then send them to the agent that wrote it, so it can address them
without you retyping the feedback.

## Add a note

- Click the add button in the diff gutter next to a line, or select a range of lines.
- Type your note in the box. Press `Enter` to save it, and `Shift+Enter` for a new line.
- The note shows the line or range it refers to.

## Send notes to an agent

- Click the send button and choose **All unsent notes** or **This file**.
- Pick an existing agent terminal, or **New agent**.
- A note is marked as sent once it reaches the agent. Editing a note marks it unsent again.
- When no notes are left to send, the button reads **All notes sent**.

There is no default keyboard shortcut for sending notes.

## Copy notes instead

The notes shelf has **Copy all notes**, and the Markdown review view has **Copy notes for agent**.
Use them to paste the notes wherever you need them.
