# File explorer

The file explorer shows the files of the current worktree in the sidebar.

## Working with files

Right-click a file or folder to:

- create a new file or folder
- rename, duplicate or delete it
- copy its path or its path relative to the worktree
- open a terminal in the folder
- open a Markdown preview
- open it in the Orca Lab browser
- download it
- find text in the folder
- add the folder as a project

## Toolbar

- **Show Git Ignored Files** and **Show Dotfiles** change which files are listed.
- **Refresh Explorer** reloads the tree.
- **Collapse All** closes every folder.
- The search box can match file names or file contents.

## Drag and drop

- Drag files from the explorer onto a terminal to paste their paths into it. The paths are quoted for the shell in that terminal, including over SSH.
- Drag a single file onto the browser to open it there.
- The composer for a new workspace accepts files dragged from your computer. It does not accept files dragged from the explorer.
