# File viewers

Orca Lab opens many file types inside the app, without an external editor.

## Images and PDFs

- Images in PNG, JPEG, GIF, SVG, WebP, BMP and ICO format open in the image viewer.
- PDFs open in the PDF viewer, with a fit-to-width option.
- Both viewers accept files up to 50 MB.

## Markdown

Markdown files (`.md` and `.mdx`) open in one of three modes:

- **Source**: the raw text.
- **Rich Editor**: a formatted editing view.
- **Preview**: the rendered page.

The Markdown menu can export the file as a PDF and show its front matter.

## Other file types

- Mermaid diagrams (`.mmd` and `.mermaid`) open in a diagram viewer.
- CSV and TSV files have a **Table** view.
- Jupyter notebooks (`.ipynb`) have a **Notebook** view.

Files that Orca Lab cannot display show "Binary file — cannot display".
