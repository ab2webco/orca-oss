# Apertura rápida

Orca Lab tiene dos paletas para moverte sin el mouse.

## Ir a un archivo

- Pulsa `Mod+P` para buscar archivos en el worktree actual.
- Orca Lab lista los archivos con ripgrep cuando está instalado, y si no, recurre a git.
- Los repositorios muy grandes pueden superar el límite de escaneo. En ese caso instala ripgrep, que hace el escaneo más rápido.

## Cambiar de worktree

- Pulsa `Mod+J` en macOS, o `Ctrl+Shift+J` en Windows y Linux.
- Busca chats y terminales recientes, worktrees, proyectos, ajustes y acciones en una sola lista.
- Escribe un nombre que no coincida con ningún worktree existente para crear uno. También puedes iniciar un worktree a partir de un enlace de GitHub o Linear.

`Mod` es Cmd en macOS y Ctrl en Windows y Linux. Ambos atajos se pueden reasignar.
