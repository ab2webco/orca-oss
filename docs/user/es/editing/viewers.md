# Visores de archivos

Orca Lab abre muchos tipos de archivo dentro de la app, sin un editor externo.

## Imágenes y PDF

- Las imágenes en formato PNG, JPEG, GIF, SVG, WebP, BMP e ICO se abren en el visor de imágenes.
- Los PDF se abren en el visor de PDF, con una opción para ajustar al ancho.
- Ambos visores aceptan archivos de hasta 50 MB.

## Markdown

Los archivos Markdown (`.md` y `.mdx`) se abren en uno de tres modos:

- **Source**: el texto sin formato.
- **Rich Editor**: una vista de edición con formato.
- **Preview**: la página renderizada.

El menú de Markdown puede exportar el archivo como PDF y mostrar su front matter.

## Otros tipos de archivo

- Los diagramas de Mermaid (`.mmd` y `.mermaid`) se abren en un visor de diagramas.
- Los archivos CSV y TSV tienen una vista **Table**.
- Los notebooks de Jupyter (`.ipynb`) tienen una vista **Notebook**.

En los archivos que Orca Lab no puede mostrar aparece "Binary file — cannot display".
