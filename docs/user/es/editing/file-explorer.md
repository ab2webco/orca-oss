# Explorador de archivos

El explorador de archivos muestra los archivos del worktree actual en la barra lateral.

## Trabajar con archivos

Haz clic derecho en un archivo o una carpeta para:

- crear un archivo o una carpeta nuevos
- cambiarle el nombre, duplicarlo o eliminarlo
- copiar su ruta o su ruta relativa al worktree
- abrir una terminal en la carpeta
- abrir una vista previa de Markdown
- abrirlo en el navegador de Orca Lab
- descargarlo
- buscar texto en la carpeta
- agregar la carpeta como proyecto

## Barra de herramientas

- **Show Git Ignored Files** y **Show Dotfiles** cambian qué archivos se listan.
- **Refresh Explorer** recarga el árbol.
- **Collapse All** cierra todas las carpetas.
- El cuadro de búsqueda puede buscar por nombres de archivo o por contenido de los archivos.

## Arrastrar y soltar

- Arrastra archivos desde el explorador a una terminal para pegar sus rutas en ella. Las rutas se entrecomillan para el shell de esa terminal, también por SSH.
- Arrastra un solo archivo al navegador para abrirlo ahí.
- El compositor de un workspace nuevo acepta archivos arrastrados desde tu computadora. No acepta archivos arrastrados desde el explorador.
