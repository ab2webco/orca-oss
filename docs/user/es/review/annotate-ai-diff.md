# Anotar diffs de IA

Puedes dejar notas en un diff y luego enviarlas al agente que lo escribió, para que las atienda sin que tengas que
volver a escribir tus comentarios.

## Agregar una nota

- Haz clic en el botón de agregar en el margen del diff, junto a una línea, o selecciona un rango de líneas.
- Escribe tu nota en el cuadro. Pulsa `Enter` para guardarla y `Shift+Enter` para una línea nueva.
- La nota muestra la línea o el rango al que se refiere.

## Enviar notas a un agente

- Haz clic en el botón de enviar y elige **All unsent notes** o **This file**.
- Elige una terminal de agente existente, o **New agent**.
- Una nota se marca como enviada cuando llega al agente. Editar una nota la vuelve a marcar como no enviada.
- Cuando no quedan notas por enviar, el botón dice **All notes sent**.

No hay un atajo de teclado predeterminado para enviar notas.

## O copiar las notas

La bandeja de notas tiene **Copy all notes**, y la vista de revisión de Markdown tiene **Copy notes for agent**.
Úsalos para pegar las notas donde las necesites.
