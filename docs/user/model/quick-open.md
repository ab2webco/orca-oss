# Quick open

Orca Lab has two palettes for jumping around without the mouse.

## Go to file

- Press `Mod+P` to search files in the current worktree.
- Orca Lab lists files with ripgrep when it is installed, and falls back to git otherwise.
- Very large repositories can exceed the scan limit. In that case install ripgrep, which makes the scan faster.

## Switch worktree

- Press `Mod+J` on macOS, or `Ctrl+Shift+J` on Windows and Linux.
- Search recent chats and terminals, worktrees, projects, settings and actions in one list.
- Type a name that does not match an existing worktree to create one. You can also start a worktree from a GitHub or Linear link.

`Mod` is Cmd on macOS and Ctrl on Windows and Linux. Both shortcuts can be remapped.
